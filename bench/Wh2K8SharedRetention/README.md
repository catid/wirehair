# Ordinary K8 shared retention: neutral instrument qualification

Tracked in `wirehair-sxvz.16.1.20.82.5.3.4.4`. This implements the observer
for gate A in [the prospective shared-call contract](../Wh2K8OrdinaryShared/Gates.md).
`Adapter.py` contains only preparation/build commands. No timing cohort has been
launched, no scientific namespace has been claimed, and defaults are unchanged.

The comparison is current versus the six-line ordinary K8 selector candidate,
using the exact native shared libraries already qualified for direct and
relocated-package consumers. It asks whether existing paths retain their
performance; it does not require an incidental certified-profile improvement.

## Reused code, not reused experiments

`Adapter.py` supplies explicit new libraries, provenance, protocol, claim path,
38-case roster, fixture checker and retention-only result combiner. It never
changes historical module globals or invokes a historical controller/receipt.

- `Wh2ProfileClassificationCostBuildR0.py` contributes only its hash-checked
  observer-source derivation and parameterized closed build. The rejected
  classification candidate and its preparation/provenance functions are unused.
- The measured `RunWork` is byte-identical to the existing shared worker. Its
  deferred-output wrapper is unchanged except for the generated include name.
  The observer authenticates six internal public bindings in **both** DSOs;
  it is not the rejected serializer's six/five-slot variant.
- `Wh2ProfileClassificationCostR0.py` supplies the 38-case fixture checker.
  The first twenty fixtures use immutable neutral compatibility data. The
  remaining eighteen use independently derived GF(256) rows, packets and rank.
  No old scientific verifier is called.
- Generic metadata, roster, statistics and raw validation come from the
  existing shared reader. The new combiner explicitly disclaims pre-admission
  restoration, ordinary K8/WH1 superiority and full historical K3 retention.
- `Wh2CurrentPreservedDeferredCostR0.py` supplies bounded neutral publication
  and output-failure checks only, not its old controller or provenance.

New provenance verifies every accepted native preparation, direct-shared and
installed-package pin. It relinks the original nineteen objects into fresh
proof DSOs with the original order/flags, replacing only the candidate Profile
object. Both proof hashes equal the actual libraries. The prior native proof
already reproduced all producer objects; this observer build does not rebuild
the production codec. Observer symbols and link inputs exclude static codecs.
