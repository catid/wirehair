# Deferred-output K5 lifecycle gate R0

Engineering successor to the permanently spent `k5-serialized-cost-r0`.
The codec-free clock-boundary diagnostic found fourteen slow computations
after two output-boundary deschedules. This motivates removing interleaved
result I/O; it does not establish the cause of every earlier excursion or
guarantee that the revised instrument passes its controls.

## Scope and frozen measurement contract

Protocol `wirehair.wh2.k5-deferred-cost-r0`; the sole scientific namespace is
`/var/tmp/wh2-k5-deferred-cost-r0`. No scientific launch is part of building or
neutral testing. Commit and pin the qualified sources before creating a claim.

The sealed GF(256) K5 core and original qualified native/scalar/sanitizer
archives remain unchanged. Compare all six independent/borrowed K5, actual WH1
and explicit certified-WH2 arms, with the same 38,880 callbacks, batch 128,
2/64/1280-byte widths, full encoder and low/distant decoder lifecycles,
both orders, 48 completion-relative phase offsets and original roster.
The first two observations per panel remain recorded preludes with their
original statistical role; no additional warm-up or exclusion is introduced.
All 108 same-code controls must satisfy their original two-percent equivalence
bounds; all 72 candidate comparisons must have an upper 95% time-ratio bound
strictly below one. No five-percent minimum, filtering, subtraction, phase
avoidance, order pooling, sample resizing or failed-control rescue is allowed.

Worker limits remain CPU 180 s, wall 210 s, timed work 150 s, address space
384 MiB. Controller limits remain worker observation 240 s, total 300 s,
raw 192 MiB, stderr 64 KiB, bundle 256 MiB. Portable and sanitizer binaries
reject scientific execution; only the original native CPU50/dispatch identity
can be a speed arm. Neutral commands are bounded checks, not speed samples.

## Publication and failure semantics

The existing static full-record array is touched before measurement through
coordinate initialization. No new logging allocation, queue or thread is
introduced. Header, record and footer formatting/printing happen only after
the complete measurement block finishes or an exception is captured. The
initial reference corpus, not potentially damaged working fixtures, supplies
the deferred header. All attempted records, including incomplete final
captures, are published in order. Publication is single-pass: a failed write
is never retried as a whole record/header, and broken pipes produce explicit
worker errors. No scientific result can pass with an incomplete record/footer,
wrong ledger, nonzero worker status or stderr output.

After abrupt process termination (for example SIGKILL or a hard resource
limit), not-yet-published memory may be unavailable. The namespace must become
INVALID; an empty/truncated stream is never success, and there is no restart
or attempt to reconstruct scientific records. Recoverable measurement failures
retain the captured prefix; an output-device failure preserves only bytes
successfully captured by the controller, not a promise of durable full output.

Neutral qualification covers 108 real WORK cases and the complete coordinate
roster, late encoder/feed/recover errors and exceptions, and three-record
publication with successful work, final recover failure/exception, final
clock failure and damaged working-source detection with an intact reference
header. Mock writers cover early/empty publication, every output step,
no retry and bounds. Real `/dev/full` and closed-pipe tests exercise stdio
error handling. The reader separately audits every emitted neutral capture;
neutral streams cannot qualify as a scientific cohort.

Historical qualification documentation is recovered at its exact Git version
and checked against its original inventory hash. Current documentation is
pinned separately; old strict verifiers and spent experiment sources are
unchanged. A scientific result does not establish installed K5 admission,
preserved K3 performance, all-K speed or construction-seed coverage.
